## What's new

- Added a Game Manager for one-click removal and restoration of imported games.
- Added recovery archives and protection for manifests shared by multiple Lua files.
- Added automatic Steam Store name lookup for games missing a local app manifest.
- Darkened the Game Manager tabs and native window title bars.
- Replaced native Windows message boxes with consistent TOST-styled dialogs.
- Added branded success, information, and warning states.
- Added scrollable message content for long installation and error reports.
- Changed the floating TOST button to a clean circular design.
- Fixed clipped menu labels while preserving the existing menu size.
- Improved menu icon rendering so symbol edges are no longer cropped.
- Preserved confirmation prompts for automatic TOST updates.
